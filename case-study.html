A reproducible pilot

Agree what success looks like before you start.

The paid pilot is US$3k for 60 days, credited on conversion to an annual license. Agree the repository set, installation work, support and success criteria during scoping.

01 / Prepare

Freeze the comparison

Choose representative change, history and onboarding tasks. Record the source commit, Engram release, indexed revision, enabled features and model settings. Have maintainers prepare an expected evidence set before participants start.

02 / Compare

Run both workflows

Use the team’s normal tools for the baseline and Engram for the assisted workflow. Keep access and task scope the same. Counterbalance task order across participants to reduce learning effects.

03 / Review

Check usefulness and gaps

Record elapsed task time, correct evidence found, important omissions, incorrect links and unanswered questions. Have a maintainer review the answers. Record indexing cost and model usage separately from query time.

Report the number and spread of runs, not just the best example. With an agreed expected set, calculate precision as correct returned items divided by all reviewed returned items; calculate recall as expected items found divided by all expected items. Keep unknown coverage and incomplete traversals visible.

Publish results only with permission from the owner of the source and measurements. Include the baseline, corpus, task definitions, configuration and limitations so another team can assess the comparison.
