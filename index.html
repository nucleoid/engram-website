Know the boundaries

Self-hosted, with
an explicit data flow.

Run Engram’s services and index on your infrastructure with versioned Docker Compose or Helm packaging. Configure repository access and choose where embeddings and optional model reasoning run.

Source text sent for embedding or reasoning goes to the providers you configure. Language coverage, index freshness and enabled features affect the evidence returned.
