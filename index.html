Features

Everything your AI assistant is missing

AI coding tools are powerful but context-blind. Engram fills the gap with deep codebase intelligence delivered through the tools you already use.

🔍

Hybrid Semantic Search

Combines vector embeddings, symbol search, and graph traversal for results that understand intent, not just keywords. Domain and component tags add precision.

🕸

Knowledge Graph

Commit history, work item relationships, and code dependencies as a traversable graph. Multi-hop queries connect code changes to the business decisions that drove them.

📞

Call Graph Analysis

Trace call sites across files and repos. Understand structural impact before making changes. Know who calls what, and what breaks if you refactor.

🔗

Cross-Repo Contracts

Automatically detects message queue contracts, HTTP API boundaries, and shared DTOs across repositories. See the coupling your team can't see.

🤖

MCP Server (25 Tools)

Native Model Context Protocol integration. Claude Code, Cursor, and any MCP-compatible tool gets direct access to search, graph traversal, and context.

🌐

Transparent API Proxy

Zero-config context injection. Sits between your AI tool and the LLM API, automatically enriching prompts with relevant code context. No agent cooperation needed.

📚

Work Item Intelligence

Full Azure DevOps work item ingestion: titles, descriptions, acceptance criteria, comments, attachments. Each section individually embedded and cross-referenced with code.

📄

Agent Doc Generation

Automatically generates AGENTS.md architecture documentation for each repo. Vendor-agnostic — works with any AI coding tool, not just Claude.

🏗

Multi-Repo Groups

Search across repository groups with fan-out queries and Reciprocal Rank Fusion merging. Microservices, monorepos, and polyglot architectures all supported.

How It Works

From zero to deep code intelligence in minutes

Engram connects to your existing version control and indexes everything automatically. No SDK, no annotations, no code changes.

1

Connect your repos

Point Engram at your Azure DevOps or GitHub repositories. Supports Git and TFVC simultaneously. Webhook-driven — indexes on every push.

2

Automatic indexing

AST parsing extracts symbols from 7 languages. Vector embeddings capture semantic meaning. Knowledge graphs map relationships. All background, all incremental.

3

Plug into your tools

Add the MCP server to Claude Code or Cursor. Or deploy the API proxy for zero-config context injection. Either way, your AI immediately understands your codebase.

4

Ship faster

Every question your AI answers now has full codebase context. No more hallucinated APIs, no more wrong patterns, no more "I don't have access to that file."
